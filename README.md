## 📈 SpreadScope

**Современное веб-приложение для мониторинга спредов между биржами и конвертации активов (фиат + криптовалюты).**

Спреды • Котировки • Конвертер • Избранное • История действий

---

## 📖 О проекте

**SpreadScope** — это система анализа котировок активов и поиска расхождений цен между разными биржами.  
Приложение позволяет отслеживать спреды по выбранным парам, фильтровать результаты по биржам и активам, а также выполнять конвертацию значений между фиатными и криптовалютными активами.

Проект ориентирован на удобный веб-интерфейс: пользователь получает доступ к таблице спредов, курсам активов, конвертеру и персональным функциям (избранные пары, история действий и журнал результатов).

---

## 🚀 Функционал

### 📊 Мониторинг котировок и спредов
- **Сравнение котировок между биржами** для одной и той же пары
- **Расчёт спреда** (абсолютное значение и процент)
- **Таблица результатов** с сортировкой по величине спреда
- **Фильтрация по биржам и парам**
- **Поиск интересующих активов**

### 💱 Конвертер активов (фиат + крипта)
- Конвертация **фиат ↔ фиат**
- Конвертация **крипта ↔ крипта**
- Конвертация **фиат ↔ крипта**
- Отображение текущего курса выбранной пары
- **Swap** (быстрая смена направления конвертации)
- Валидация ввода и сообщения об ошибках

### ⭐ Персональные функции (для авторизованных пользователей)
- **Избранные пары / Watchlist**
- Сохранение интересующих пар для быстрого доступа
- Персональная **история действий**
  - просмотры пар
  - конвертации
  - пользовательские отметки
- **Журнал результатов / сделок**
  - пользователь может зафиксировать событие
  - указать комментарий и результат
  - просматривать историю своих записей

### 🎨 UI/UX (веб-интерфейс)
- Адаптивный интерфейс (Desktop / Mobile)
- Удобная таблица спредов и фильтры
- Интерактивный конвертер
- Быстрая навигация между разделами
- (Планируется) графики и алерты

## 🧩 Основные модули системы

- **Источники данных**
  - получение котировок из локальных данных / API
  - обработка ошибок источников

- **Нормализация пар**
  - приведение форматов торговых пар к единому виду
  - объединение одинаковых пар из разных источников

- **Расчёт спредов**
  - вычисление спредов между биржами
  - сортировка и фильтрация результатов

- **Конвертер**
  - пересчёт значений между активами
  - отображение курса и результата
  - валидация ввода

- **Пользовательские данные**
  - авторизация
  - избранные пары
  - история действий
  - журнал результатов
