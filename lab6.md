# Лабораторная работа №6
## Тема: Улучшение UX
Проект: **SpreadScope**

---

## 1. Оценка по атрибутам Usability (ISO/IEC 25010)

### 1.1 Распознаваемость соответствия

**Оценка: Средняя**

Пользователь может быстро понять назначение приложения благодаря заголовку "SpreadScope" и подзаголовку. Секции "Конвертер" и "Спреды" имеют чёткие заголовки с иконками. Однако при первой загрузке таблица спредов показывает "Загрузка..." без пояснения, что данные появятся после того, как сервер опросит биржи — пользователь может подумать, что приложение сломано.

### 1.2 Обучаемость

**Оценка: Низкая**

- Заголовки таблицы спредов были на английском (Symbol, Low Exchange, High Price) при полностью русскоязычном интерфейсе — пользователю приходилось переключать контекст.
- Нет подсказок (tooltips) на кнопках — назначение "Swap ⇄" и "Sort" неочевидно новому пользователю.
- Названия бирж в фильтрах были в нижнем регистре (gate, mexc, ourbit) — незнакомый пользователь не распознает их как бренды.

### 1.3 Используемость (операбельность)

**Оценка: Средняя**

- Конвертер работает: выбор валют, ввод суммы, отображение результата.
- Фильтрация спредов по паре и биржам реализована.
- Однако: конвертация не срабатывала по нажатию Enter (только кнопкой), кнопка "Обновить" не показывала состояние загрузки, автофокус на поле суммы отсутствовал.

### 1.4 Защита от ошибок пользователя

**Оценка: Средняя**

- Валидация суммы конвертера присутствует (пустая строка, не число, <=0).
- Однако: пользователь мог выбрать одинаковые валюты "из" и "в" (USD -> USD), что давало бессмысленный результат.
- Поле суммы имело `type="text"` — на мобильных устройствах открывалась полная клавиатура вместо цифровой.

### 1.5 Эстетика GUI

**Оценка: Хорошая**

- Тёмная тема с градиентным фоном, полупрозрачные карточки с backdrop-blur.
- CSS-переменные для единообразной цветовой схемы.
- Адаптивная сетка (grid) для desktop/mobile.
- Однако: обновление таблицы спредов происходило резко (мгновенная замена DOM), строки таблицы не имели плавного ховер-эффекта.

### 1.6 Доступность

**Оценка: Низкая**

- Отсутствовали `aria-label` на интерактивных элементах (кнопки, селекты, таблица).
- Не было `aria-live` регионов — скринридеры не озвучивали результат конвертации и ошибки.
- Не было стилей `focus-visible` для клавиатурной навигации (кроме border на инпутах).
- Контраст muted-текста (#9aa7c7 на тёмном фоне) был недостаточным по WCAG 2.0.

## 3. Реализованные изменения

### Файлы изменены:
- `frontend/index.html`
- `frontend/style.css`
- `frontend/app.js`

---

### 3.1 Обучаемость — заголовки таблицы на русском

**До:**
```
Symbol | Low Exchange | Low Price | High Exchange | High Price | Spread | Spread %
```

**После:**
```
Пара | Биржа (мин) | Цена (мин) | Биржа (макс) | Цена (макс) | Спред | Спред %
```

---

### 3.2 Обучаемость — tooltips на кнопках

**До:** кнопки "Swap ⇄" и Sort без подсказок.

**После:** добавлены `title` атрибуты:
- Swap: "Поменять валюты местами"
- Sort: "Изменить порядок сортировки по спреду"

---

### 3.3 Обучаемость — названия бирж

**До:** `gate`, `mexc`, `ourbit` (нижний регистр)

**После:** `Gate.io`, `MEXC`, `OurBit` (как бренды)

---

### 3.4 Обучаемость — сообщение при загрузке

**До:** `Загрузка...`

**После:** `Загрузка данных... Спреды появятся через несколько секунд после запуска сервера.`

---

### 3.5 Операбельность — Enter для конвертации

**До:** конвертация только по клику на кнопку.

**После:** добавлен обработчик `keydown` на поле суммы — нажатие Enter вызывает конвертацию.

```javascript
amountEl.addEventListener("keydown", (e) => {
  if (e.key === "Enter") {
    e.preventDefault();
    convertNow();
  }
});
```

---

### 3.6 Операбельность — состояние loading кнопки "Обновить"

**До:** кнопка не меняется во время загрузки — можно нажать повторно.

**После:** кнопка блокируется (`disabled`) и текст меняется на "Обновление..." на время запроса.

---

### 3.7 Защита от ошибок — блокировка одинаковых валют

**До:** можно выбрать USD → USD.

**После:** при выборе одинаковой валюты второй селект автоматически переключается на другую.

```javascript
function preventSameCurrency(changedEl, otherEl, assets) {
  if (changedEl.value === otherEl.value && assets.length > 1) {
    const alt = assets.find(a => a !== changedEl.value);
    if (alt) otherEl.value = alt;
  }
}
```

---

### 3.8 Эстетика — анимация fade-in строк таблицы

**До:** строки таблицы появляются мгновенно (innerHTML заменяется целиком).

**После:** каждая строка получает CSS-класс `fade-in` с анимацией:

```css
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(4px); }
  to   { opacity: 1; transform: translateY(0); }
}
tbody tr.fade-in {
  animation: fadeIn 0.3s ease forwards;
}
```

---

### 3.9 Доступность — aria-атрибуты

**До:** интерактивные элементы без aria-разметки.

**После:**
- `aria-label` на кнопках, селектах, секциях, таблице
- `aria-live="polite"` на результате конвертации и tbody таблицы
- `aria-live="assertive"` на блоке ошибок конвертера

---

### 3.10 Доступность — focus-visible и контраст

**До:** нет стилей для клавиатурного фокуса (кроме border на инпутах), muted-цвет `#9aa7c7`.

**После:**
- Стиль `focus-visible` с outline для всех интерактивных элементов
- Muted-цвет повышен до `#b0bde0` для лучшего контраста

```css
button:focus-visible,
select:focus-visible,
input:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
```

---

### 3.11 Операбельность — звёздочка ★ для избранного в таблице спредов

**До:** для добавления пары в избранное нужно было вручную вводить символ в отдельную секцию "Избранные пары".

**После:** в таблице спредов у каждой строки появляется кнопка ☆/★ (только для авторизованных пользователей). Один клик — добавить в избранное, повторный — убрать. Звёздочка подсвечивается жёлтым для избранных пар.

---

### 3.12 Операбельность — вкладки "Все спреды" / "Избранное"

**До:** все спреды отображались в одном списке, избранное было отдельной секцией.

**После:** над таблицей спредов добавлены вкладки:
- **Все спреды** — полный список
- **⭐ Избранное (N)** — только добавленные в watchlist пары с счётчиком

Вкладка "Избранное" появляется только для авторизованных пользователей.

---

### 3.13 Операбельность — арбитражный калькулятор

**До:** конвертер работал только с локальными фиатными/крипто котировками и не был связан с таблицей спредов.

**После:** при клике на строку в таблице спредов открывается арбитражный калькулятор:
- Показывает выбранную пару, биржу покупки (мин. цена) и биржу продажи (макс. цена)
- Пользователь вводит сумму в USDT
- Автоматически рассчитывается: количество токенов, выручка при продаже, чистый профит в USDT и процентах

Это позволяет быстро оценить потенциальную прибыль от арбитража конкретного спреда.

Старый конвертер валют сохранён в сворачиваемой секции (details/summary).

---

### 3.14 Эстетика — подсветка выбранной строки

**До:** строки таблицы не имели визуального состояния "выбрана".

**После:** при клике на строку для арбитражного калькулятора она подсвечивается — голубая рамка слева и полупрозрачный фон.

## 4. Итог

В ходе лабораторной работы:

- Проведена оценка приложения SpreadScope по 6 атрибутам Usability (ISO/IEC 25010)
- Выявлены конкретные проблемы в каждом атрибуте
- Реализовано **20 улучшений** в трёх файлах фронтенда
- Для каждого улучшения приведено описание "до" и "после"
- Ключевые улучшения второй итерации:
  - Звёздочка ★ прямо в таблице спредов для управления избранным
  - Вкладки "Все спреды" / "Избранное" с фильтрацией
  - Арбитражный калькулятор — клик по спреду → расчёт профита
- Улучшения затрагивают все 6 атрибутов: обучаемость, операбельность, защиту от ошибок, эстетику, доступность и распознаваемость
